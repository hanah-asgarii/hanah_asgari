# Portfolio Site

## Files
- `index.html` = the page structure
- `style.css` = the design
- `images/` = place for smaller images
- `cv.pdf` = put your CV here

## Before publishing
1. Open `index.html`.
2. Replace `Your Name` with your name.
3. Replace the contact information.
4. Put your CV in this folder and name it `cv.pdf`.

The dashed boxes are placeholders. Large videos should NOT be uploaded to GitHub. Host them elsewhere and later replace the placeholders with embedded video links.
